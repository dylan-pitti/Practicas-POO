# Lab4 - Practicas-POO

 
Repositorio para la entrega del Laboratorio: Practicas-POO y desarrollado por Dylan Pitti del salón 1S3122
 
 
Es un laboratorio enfocado en los fundamentos de la Programación Orientada a Objetos, también incluyendo distintas clases y ejemplos.
## Contenidos del Repositorio
 
| Archivo | Descripción |
|---|---|
| `Circulo.php` | Clase simple en donde se calculan tanto el perímetro como el área de un círculo |
| `Class_A.php` | Clase en donde se imprime una de las clases gracias al "extends" |
| `Coche.php` | Código con la clase coche; se imprimen el color de un carro y extras de este |
| `Error_Coche.php` | Código que crea a propósito un error de "unexpected token class"|
| `Persona.php` | Clase principal creada para añadir atributos al estudiante.php |
| `Estudiante.php` | Se imprimen varios datos de los estudiantes gracias a los atributos heredados del persona.php|

##  Cómo ejecutar el proyecto
 
1. Clonar el repositorio:
```bash
   git clone https://github.com/dylan-pitti/Include---Formularios-HTML5.git
```
2. Colocarlo dentro del directorio de tu servidor local (www si se usa WAMP o LAMP).
3. Iniciar Wamp o Lamp después conectarse al servidor local mediante hhtp://127.1.1.1
4. Elegir el archivo a probar dentro de la carpeta asignada (el index.php)
